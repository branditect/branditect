Build notes

Image placeholders

Product thumbnails are grey tiles with a picture glyph. Swap for real shots — .thumb in the CSS. Everything else is real markup, not an image.

The panels are UI, not screenshots

Brand Health, Products, Studio and AI Chat are built from the same tokens as the app, so they stay sharp at any zoom and can be updated when the product changes.

Three SSO buttons need three integrations

Google, Microsoft and Apple are each separate OAuth work. Ship the ones you've wired and delete the rest — a dead SSO button is the worst first interaction a new user can have.

Remember me is a real decision

It changes session lifetime, so it needs backend support. If it isn't wired, take it out rather than showing a checkbox that does nothing.

Panels hide below 1180px

Then the five feature cards reflow to a grid, and below 860px everything stacks with the pitch above the form. The login card never gets pushed off-screen.

87% is illustrative

It's marketing furniture on this screen, not a live figure. Keep it fixed — don't wire it to a real account, or the login page starts leaking data before anyone signs in.
